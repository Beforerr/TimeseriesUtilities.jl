TimeseriesUtilities.cadence — Method
cadence(ts; rtol=1e-3, check=true)

Robust sampling cadence of times ts via IQR-trimmed modal clustering on positive diffs, refined by the median of diffs within rtol of the modal center. With check=true, warns on gaps or intervals off integer multiples of the cadence by more than rtol.

TimeseriesUtilities.mapsamples — Method
mapsamples(f, A, args...; dim=nothing)

Apply f to each sample of A and the matching samples of args, and stack results along time. Each argument is sliced along its own time dimension. When selected axes have coordinates, their keys must match; otherwise samples are paired by position. Arguments without axes (scalars, Ref(v)) are passed whole to every call.

Time sits at position dim of the result, clamped to last when results have too few axes. Results the size of a sample keep the other axes of A; other results get anonymous axes.

Samples are views; for small vectors, converting them to SVectors avoids per-sample allocation, e.g. mapsamples((e, b) -> cross(SVector{3}(e), SVector{3}(b)), E, B).

TimeseriesUtilities.outlier_mask — Function
outlier_mask(A, [window]; threshold=3, dim=nothing)

Boolean mask (like A) of the values of each channel of A more than threshold scaled median absolute deviations (MAD) from the median along time (or dim); NaNs are never outliers. The statistics are global, or local over a moving window around each sample as in tsmooth (counted in samples for a plain array).

See also: despike, isoutlier - MATLAB

TimeseriesUtilities.rebuild — Method
rebuild(x, data, dims::Tuple)
rebuild(x, data, dim::Integer, keys)
rebuild(x, data)

Container like x holding data, with axes dims: each Val(i) (dimension i of x as it is, with whatever the container attaches to it), Val(i) => keys (dimension i with new samples), name::Symbol => keys (new named dimension) or nothing => keys (new anonymous dimension). keys is nothing for an axis without coordinates; backends that cannot represent that supply positions.

Backends implement the 3-argument form, and the shorthands only where that is cheaper. Plain arrays rebuild to data; containers without a method throw rather than silently drop their keys.

TimeseriesUtilities.tfill_gaps — Function
tfill_gaps(A, [dt]; fill = NaN, max_gap = nothing, dim = nothing)

Insert missing timestamps (new samples set to fill); originals are kept exactly. A gap Δ gets round(Δ / dt) - 1 points at t[i] + k * dt; gaps Δ > max_gap are left open. dt defaults to cadence. Float eltypes are kept; others promote to fit fill.

Zero-phase bandpass filter A between Wn1 and Wn2 hertz; the upper cutoff defaults to just below Nyquist. Requires DSP.jl.

TimeseriesUtilities.tinterp — Method
tinterp(A, t; interp=LinearInterpolation, dim=nothing, kws...)

Interpolate A at time t, or at each of times t (keyed by t).

The interp constructor must accept (u, t; kws...) and return a callable object.

Examples

# Interpolate at a single time point
tinterp(time_series, DateTime("2023-01-01T12:00:00"))

# Interpolate at multiple time points using cubic spline interpolation
new_times = DateTime("2023-01-01"):Hour(1):DateTime("2023-01-02")
tinterp(time_series, new_times; interp = CubicSpline)

TimeseriesUtilities.tsmooth — Method
tsmooth([f=nanmean], x, window; dim=nothing)

Moving statistic f of x along dim over the windows [c - before, c + after) around each coordinate c; a scalar window is split evenly into before and after. f receives one channel's samples in a window as a vector. Edge windows are truncated, so the output has the size of x.

Coordinates are the axis keys of x; for a plain array they are sample indices, so window counts samples.

TimeseriesUtilities.tsync — Method
tsync(A, Bs...; dim=nothing, kws...)

Synchronize multiple time series to have the same time points.

This function aligns time series Bs... to match time points of A by:

  1. Finding common time range between all time series
  2. Extracting subset of A within common range
  3. Interpolating each series in Bs... to match the time points of the subset of A, with tinterp(B, t; kws...)

Examples

A_sync, B_sync, C_sync = tsync(A, B, C)
